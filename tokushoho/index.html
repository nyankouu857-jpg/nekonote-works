ねこのて工房 が Gumroad・Tips などの販売プラットフォームで販売するデジタル商品 (テンプレート・設定パック・手順書など) についての表記です。販売を始めたプラットフォームでは、プロフィールにも同じ内容を掲載します。

販売業者

項目 内容
販売業者 ねこのて工房
氏名・住所・電話番号 ご請求があれば開示します (下記参照)
連絡先 https://github.com/nyankouu857-jpg/nekonote-works/issues

氏名・住所・電話番号は、ご請求があれば遅滞なく電子メール等で開示します。これは、消費者庁が示す通信販売の広告表示の省略の扱いに基づくものです。開示をご希望の場合は、上記の連絡先に「特定商取引法に基づく表記の開示請求」とご記入ください。連絡先が GitHub の Issue の場合、投稿は誰でも閲覧できるため、氏名やメールアドレスなどの個人情報は書かずに「開示請求」とだけご記入ください。運営者から非公開の連絡方法をご案内し、遅滞なく開示します。

販売価格

各商品・各記事の販売ページに表示する価格とします。Gumroad では、税を含む最終的なお支払額が決済画面に表示されます。

商品代金以外の必要料金

インターネット接続に必要な通信料は購入者のご負担となります。米ドル建ての商品は、ご利用のカード会社が定める為替レートと手数料が適用される場合があります。

支払方法と支払時期

各販売プラットフォームが提供する決済手段 (クレジットカード等) でお支払いいただけます。お支払いは購入手続きの完了時に確定します。詳細は各プラットフォームの規約に従います。

商品の引渡時期

決済完了後、すぐにダウンロードできます。Tips の記事は、決済完了後すぐに有料部分を閲覧できます。

返品・キャンセルについて

デジタルコンテンツの性質上、ダウンロード後 (Tips の記事は購入後) の返品・キャンセル・返金はお受けできません。

ファイルが開けないなどの不具合があった場合は、上記の連絡先までご連絡ください。Gumroad で購入された商品は、確認後にファイルの再送または返金で対応します。Tips で購入された記事は、確認のうえ Tips の規約に沿って対応します。

動作環境

各商品の販売ページと、商品に同梱する README に記載します。

AI の利用について

商品と Tips の記事の制作には AI (Anthropic の Claude) を活用しています。Gumroad で販売する商品は、公開前に自動検査と別工程の AI レビューを行っています。Tips の記事は、公開前に自動検査を行っています。詳しくは AI の利用方針 をご覧ください。

販売ページ

販売中の商品と販売ページへのリンクは 商品カタログ にまとめています。
