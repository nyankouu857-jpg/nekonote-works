つくっているもの

ねこのて工房は、Claude Code を Windows で無人運用するための設定パックと、日本の制度に合わせた請求書・チェックリストなどの実務テンプレートを制作・販売しています。

  • AI コーディングツールの運用パック (Claude Code 向け・非公式): CLAUDE.md のテンプレート、hooks、Windows と PowerShell で無人実行するための雛形、権限設計、ログと停止スイッチの雛形
  • 日本仕様のスプレッドシート テンプレート: 消費税 10%/8%・インボイスの登録番号・源泉徴収の欄を備えた請求書など。数式を検査してから公開します
  • ワークフロー集: 議事録からのタスク化など、1 つの作業を完結させるためのプロンプトと手順
  • チェックリスト: 個人開発のリリース前確認、OSS 公開前の確認など。法的助言ではありません

販売中の商品は 商品カタログ にまとめています。購入とダウンロードは Gumroad などの販売プラットフォームで行います。

AI の利用方針

商品と記事の制作には AI (Anthropic の Claude) を活用しています。公開前に自動検査 (禁止表現・類似度など) を行い、Gumroad で販売する商品はさらに別工程の AI レビューを通します。そのうえで次の方針を守ります。

  • 検証していない数値、架空の利用者の声、販売実績や購入者数は掲載しません。
  • 手順や設定値には、確認した環境と確認の方法を添えます。
  • 規約・法令・料金など変わりうる情報には、確認先として一次情報の URL を添えます。
  • 誤りが見つかった場合は訂正し、更新日を改めます。誤りに気づかれた際は お問い合わせ からご指摘ください。

広告表記について

当サイトで広告やアフィリエイトリンクを掲載する場合は、景品表示法のステルスマーケティング規制に沿って、該当する記事の冒頭に「PR」と表示し、広告リンクには rel="sponsored" 属性を付けます。報酬の有無によって商品・サービスの評価を変えることはありません。

運営者自身の商品を紹介するときは、運営者が販売する商品であることを明示し、第三者の感想や口コミの体裁はとりません。
