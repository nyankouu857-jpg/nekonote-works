お問い合わせ

目次

当サイトと販売している商品に関するご連絡は、以下の窓口で受け付けています。

連絡先

https://github.com/nyankouu857-jpg/nekonote-works/issues

GitHub の Issue をご利用の場合

  • GitHub のアカウントでログインし、上記ページから新しい Issue を作成してください。
  • Issue は誰でも閲覧できる公開の場です。氏名・メールアドレス・注文番号などの個人情報は書き込まないでください。
  • 個別のやり取りが必要な場合は、運営者から非公開の連絡方法をご案内します。

メールでの窓口を追加した場合は、このページと 特定商取引法に基づく表記 に掲載します。

お問い合わせの対象

  • 購入した商品の不具合 (ファイルが開けない、手順どおりに動かないなど)
  • 記事・商品説明の誤りのご指摘・訂正依頼
  • 特定商取引法に基づく表記の開示のご請求
  • 掲載内容の削除依頼
  • その他、当サイトに関するご意見

ご注意

  • 返信には数日かかる場合があります。内容によっては返信できないことがあります。
  • 営業・勧誘を目的としたご連絡にはお答えしていません。
  • いただいた個人情報は プライバシーポリシー に基づいて取り扱います。
