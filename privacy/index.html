当サイト「ねこのて工房」は、利用者の個人情報の取扱いについて以下のとおり定めます。本ポリシーにおける個人情報の取扱事業者は、運営者情報 に記載の運営者です。

個人情報の取得と利用目的

当サイトでは、お問い合わせの際に氏名・メールアドレスなどの個人情報をご提供いただく場合があります。取得した個人情報は、お問い合わせへの回答と必要な情報のご連絡のみに利用し、法令に基づく場合を除き第三者に提供しません。

GitHub の Issue でお問い合わせいただいた内容は、GitHub 上で公開されます。個人情報は Issue に書き込まないでください。

購入者の情報について

商品の決済は Gumroad・Tips などの販売プラットフォームが行い、カード番号などの決済情報を運営者が受け取ることはありません。販売プラットフォームから運営者に購入者の情報 (メールアドレスなど) が提供される場合、その情報は商品の提供、不具合への対応、法令上の義務の履行のためにのみ利用します。各プラットフォームでの個人情報の取扱いは、それぞれのプライバシーポリシーをご確認ください。

Cookie の利用について

当サイトは、アクセス解析や広告配信のサービスを利用する場合に Cookie を使用することがあります。Cookie は利用者のブラウザを識別しますが、氏名や住所などの個人を特定する情報は含みません。ブラウザの設定で Cookie を無効にできますが、一部の機能が利用できなくなる場合があります。

アクセス解析ツールについて

当サイトは、Google が提供するアクセス解析ツール「Google アナリティクス」を利用する場合があります。利用する場合、Google アナリティクスはトラフィックデータの収集のために Cookie を使用します。このデータは匿名で収集されており、個人を特定するものではありません。Cookie を無効にすることで収集を拒否できます。詳細は Google アナリティクス利用規約 および Google のプライバシーポリシー をご確認ください。

広告配信について

当サイトは、第三者配信の広告サービス「Google AdSense」を利用する場合があります。利用する場合、Google などの第三者配信事業者は、利用者が当サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信するために Cookie を使用します。Google による広告 Cookie の利用については Google のポリシーと規約「広告」 をご確認ください。パーソナライズ広告は Google の広告設定 で無効にできます。また、www.aboutads.info から第三者配信事業者の Cookie を無効にすることもできます。

アフィリエイトプログラムについて

当サイトがアフィリエイトプログラムに参加する場合、成果の計測のために提携先が Cookie を使用します。アフィリエイト広告を含む記事には冒頭に「PR」と表示します。詳細は 広告表記について をご確認ください。

ホスティングとアクセスログ

当サイトは GitHub, Inc. が提供する GitHub Pages 上で公開しています。GitHub は、サービスの提供と安全性の確保のために、閲覧者の IP アドレスなどのアクセスログを取得する場合があります。詳細は GitHub の一般プライバシーステートメント をご確認ください。

免責事項

当サイトの情報の利用に関する免責については 免責事項 をご確認ください。

著作権

当サイトに掲載している文章・画像などの著作権は、当サイト運営者または正当な権利者に帰属します。引用の際は出典として当サイト名と URL を明記してください。

保有個人データの開示等のご請求

ご本人から、保有個人データの利用目的の通知、開示、訂正・追加・削除、利用停止・消去、第三者提供の停止のご請求があった場合は、ご本人であることを確認したうえで、個人情報の保護に関する法律に従って遅滞なく対応します。ご請求は お問い合わせ の窓口で受け付けます。窓口が公開の Issue の場合は個人情報を書かず、「個人情報の開示等の請求」とだけご記入ください。運営者から非公開の連絡方法をご案内します。運営者の氏名・住所と、保有個人データの安全管理のために講じた措置は、ご請求があれば遅滞なく回答します。

本ポリシーの変更

本ポリシーは、法令の改正やサービス内容の変更に応じて改定することがあります。改定後の内容は本ページに掲載した時点で効力を生じます。

お問い合わせ

本ポリシーに関するお問い合わせは お問い合わせページ からお願いします。
